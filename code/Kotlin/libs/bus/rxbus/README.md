#RxBus
支持自定义消息的消息传递

用法示例
---
```kotlin
fun useBus() {
    Bus.get().with(owner).onMessage(0) {
        finish()
    }

    RxBus.send(0, "ss 0")
    RxBus.send(1, "ss 1")
    RxBus.send(2, "ss 2")
}
```
result:
```text
  ┌────────────────────────────────────────────────────────────
    | 收到了 code = 0
    | 收到了 any = ss 0
    └────────────────────────────────────────────────────────────
    (L.java:400)
    ┌────────────────────────────────────────────────────────────
    | 收到了 code = 2
    | 收到了 any = ss 2
    └────────────────────────────────────────────────────────────
```
